## Active Architecture & Production Rules
1. **Scene Extension Workflow:**
   - Single approved 10-second base clip with Gemini Omni 1.1 Flash & tokenized `@Creator`.
   - Scene Extension 1 (10–20s) generated by attaching the accepted parent video via `Add to prompt` / context continuation.
   - Scene Extension 2 (20–30s) continuing the accepted parent chain.
2. **Strict Quality Gates:**
   - Stages: `base` -> `ext1` -> `ext2` with explicit states: `GENERATED`, `QC_PASS`, `QC_FAIL`, `ACCEPTED_PARENT`, `DISCARDED_CHILD`.
   - Only `ACCEPTED_PARENT` can be extended. Max 3 retries per parent.
3. **No Silent Fallback:**
   - If native Scene Extension / video continuation controls are blocked or unavailable in Flow UI, report as a blocker immediately; do NOT silently revert to independent 3x10s or frame-cut concat scripts.
